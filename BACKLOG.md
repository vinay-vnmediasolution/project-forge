## Prioritisation test

Before moving an item to ready, ask:

1. Does it develop a target FDE capability?
2. Does it solve or illuminate a real problem?
3. Is it the smallest useful next increment?
4. Can it be completed within available capacity?
5. What existing item will it displace?
