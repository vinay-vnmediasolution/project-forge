## Coaching rules

- Use a rolling cycle rather than fixed weekdays
- A missed session does not reset the plan; continue with the next session in sequence
- Main progression method: double progression plus RIR
- Typical interpretation:
  - 0 RIR: maximal; do not automatically increase
  - 1–2 RIR: ideal working load
  - 3–4 RIR: consider increasing next set/session
  - 5+ RIR: clearly underloaded
- Technique failure ends a set even if muscular reps remain
- Lower-body compounds may use ramping sets to find the day’s working load
- Smith squat and free-bar squat are tracked independently
