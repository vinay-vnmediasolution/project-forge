# Forge Athletic — Rolling Program and Next Session

_Last updated: 2026-08-06_

## Program principles

- The program is rolling, not tied to weekdays.
- Missing a day does not change the order; continue with the next suitable session.
- Recovery days are inserted based on soreness, sleep, energy, cricket and schedule.
- Optional Arms + Core can be used as a floating session, but should not repeatedly replace legs.
- Most working sets should finish around 1–2 RIR.
- Reaching 0 RIR is acceptable occasionally on a final/top set, not on every set.

## Rolling sequence

1. Push A
2. Legs A
3. Pull A
4. Recovery if required
5. Push B
6. Legs B
7. Pull B
8. Optional Arms + Core when useful
9. Repeat

## Progression algorithm

Use double progression:

1. Pick a rep range, usually 8–10 or 10–12.
2. Keep the load until all prescribed sets reach the top of the range with good form and about 1–2 RIR.
3. Increase by the smallest practical increment.
4. If a set reaches 0 RIR or form breaks, do not automatically increase next time.
5. Treat the first set as calibration when using an unfamiliar machine.

## Recovery guidance

- After 2–3 consecutive strength days, consider a recovery day.
- Recovery day target: 8,000–12,000 steps plus 10–15 minutes mobility.
- Sleep target: 7.5–8.5 hours.
- Continue creatine 5 g daily.
- Protein target: 150–170 g/day.
