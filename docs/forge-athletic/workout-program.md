# Project Athletic 80 - Workout Program

## Philosophy
- Rolling Push/Legs/Pull cycle (not tied to weekdays).
- If a workout is missed, continue with the next workout in sequence.
- Progress using RIR (1-2 reps in reserve).

## Cycle
Push A
Legs A
Pull A
Recovery
Push B
Legs B
Pull B
Repeat

## Push A
1. Incline Dumbbell Press
2. Machine Chest Press
3. Seated Shoulder Press
4. Lateral Raises
5. Rope Triceps Pushdown
6. Overhead Triceps Extension

## Legs A
1. Back Squat
2. Romanian Deadlift
3. Leg Press
4. Leg Extension
5. Seated Calf Raise
6. Hanging Knee Raise

## Pull A
1. Pull-ups
2. Single-arm Dumbbell Row
3. Lat Pulldown
4. Seated Cable Row
5. EZ Bar Curl
6. Hammer Curl

## Push B
1. Flat Barbell Bench Press
2. Incline Dumbbell Press
3. Machine Chest Press
4. Lateral Raises
5. Cable Triceps Pushdown
6. Overhead Triceps Extension

## Legs B
1. Front Squat or Hack Squat
2. Walking Lunges
3. Hamstring Curl
4. Leg Press
5. Standing or Seated Calf Raise
6. Core

## Pull B
1. Pull-ups or Assisted Pull-ups
2. Chest Supported Row
3. Wide Grip Lat Pulldown
4. Cable Row Variation
5. EZ Bar Curl
6. Hammer Curl

## Progression
Increase weight only after completing target reps with good form and 1-2 RIR.
