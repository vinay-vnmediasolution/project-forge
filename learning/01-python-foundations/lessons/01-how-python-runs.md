## Learning objective

Explain the relationship between Python source code, the interpreter, runtime execution, values, objects, names, and types.

## Lesson plan

1. Where Python fits in a software system
2. Source code, interpreter, bytecode, and runtime
3. Values, objects, names, and assignment
4. Built-in types
5. Dynamic versus static typing
6. Comparison with C# and .NET
7. Execution-tracing knowledge check
8. Small independent exercise
9. Teach-back and reflection

The curated explanation will be added as the lesson is taught and reviewed. This file is intentionally not pre-filled with an AI-written textbook.
